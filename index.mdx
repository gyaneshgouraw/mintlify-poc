# Hello Mintlify

This is the home page. Every page is an `.mdx` file: Markdown plus React
components.

<Note>
  This callout is a built-in Mintlify component. You get these without any
  setup.
</Note>

## What is going on here

- `docs.json` defines config: theme, colours, and the navigation sidebar.
- Each entry in `navigation.groups[].pages` maps to an `.mdx` file (no
  extension needed).
- Content is written in MDX.
